# Sites of src/Generator that turn emitted C# text into a Roslyn tree (CSharpSyntaxTree.Parse*, SyntaxFactory.Parse*)
# or reformat one (NormalizeWhitespace) instead of building it through Neemle.CSharpComposer (ORML-150).
# The Composer-only gate (tests/Tests/Gates/GeneratorComposerOnlyTests) refuses every Composer escape; these Roslyn
# sites are the recorded exceptions to building through Composer, each with its reason, and
# GeneratorRoslynParseCensusTests keeps this list exact: a site that is not listed fails, a count that differs fails,
# and a listed site that is gone fails, so a new site needs a line and a reason here and a converted one takes its line
# away.
# One line per file and call: <path under src/Generator> TAB <call> TAB <count> TAB <reason>.
#
# Why they are exceptions: EntityEmitter.EmitEntities renders ONE Composer document for all entities and then runs
# five augment passes over the rendered text (relation-loading policies, one-to-one loaders, graph-save bindings,
# orphan registrations, join columns). Each pass parses that text with Roslyn, adds members whose source its emitter
# writes as strings, and prints the tree again; GeneratedSourceLayout then splits the text into one file per type and
# GeneratedLineWrap wraps its long lines. Building these members through Composer means rewriting the string emitters
# (SaveBindingEmitter, OrphanBootstrapEmitter, Policy*Emitter, OneToOneLoader, JoinCodecEmitter) as typed Composer
# builders applied before the one render, and splitting into per-type documents before rendering: a generator rewrite
# with no change in the code it generates, left out of ORML-150 under process:keep-it-simple-speed.
GeneratedSourceLayout/GeneratedLineWrap.cs	CSharpSyntaxTree.ParseText	1	wraps lines over 120 characters of the final text, after the augment passes; Composer's RenderOptions.MaxLineLength cannot reach members Composer did not render
GeneratedSourceLayout/GeneratedSourceLayout.cs	CSharpSyntaxTree.ParseText	1	splits the one rendered and augmented document into one hint file per type (OrmLite.Entities.NNNN.g.cs)
